# Movie Marathon Calculator

A web application to calculate the exact total runtime of movie franchises and custom movie marathons.

## Current Status

**Work in Progress**
The repository currently contains the initial setup. The application is not yet functional.

## Architecture & Data

- **Objective:** Enable users to search for specific movies, compile them into a list, and calculate the cumulative runtime for a single sitting.
- **API Integration:** All movie metadata, including accurate runtimes, will be fetched dynamically using the TMDB API.

## Planned Features

- Real-time search and selection of movies via TMDB
- Cumulative runtime calculation for custom lists
- Automatic suggestion of break intervals between movies
- Pre-defined quick selections for popular franchises (e.g., Lord of the Rings, Harry Potter)
